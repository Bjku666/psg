# Counterfactual relation verification v1

This line tests whether a frozen relation edit can be verified as rescue,
neutral, or harm under the corrected PSG evaluator. It is a new protocol; the
historical `evidence_accessibility_v1` line remains closed and its artifacts
are not joined or repaired.

The first executable gate is B0: one inference pass must emit immutable,
action-conditioned records containing identity, frozen Top-50 support, logits,
geometry, and subject/object/union evidence. The exact utility teacher may
only attach to those records. Any missing or duplicate key blocks training.

Large datasets, checkpoints, caches, and source snapshots live under
`/data1/liuhaoran/psg`. No GPU method training is authorized until C0--E0/E4
diagnostics pass their registered gates.
