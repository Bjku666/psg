# P1 v2 corrected actionability contract

`gssr_p1_v1` is frozen as `replay_contract_invalidated_before_evidence`.
Restricting final native survivors before rerunning Mask2Former changes the
pixel-competition population, so its replay cannot identify entity admission.

`gssr_p1_v2` intervenes after one full-pool semantic eligibility and pixel
competition pass. Each candidate stores its mutually-exclusive winning mask,
won area, original area, area ratio, class and score. Counterfactuals only
select a fixed-K subset of these candidates and assemble the stored masks.

The exporter supports `--split train|test|all` and `--file-list`; P1 evidence
uses official train only and the grouped fit/dev/confirm splitter. Artifacts
keep learner features and mask logits in float16 while class logits, winner
maps, native segmentation, official segment metadata, and query provenance are
stored losslessly enough for the corrected assembly sanity checks.

No learner is authorized until dev actionability reaches both the registered
delta and actionable-fraction gates; confirm is a one-time post-freeze check.
