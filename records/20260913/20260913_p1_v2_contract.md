# P1 v2 corrected actionability contract

`gssr_p1_v1` is frozen as `replay_contract_invalidated_before_evidence`.
Restricting final native survivors before rerunning Mask2Former changes the
pixel-competition population, so its replay cannot identify entity admission.

`gssr_p1_v2` intervenes after one full-pool semantic eligibility and pixel
competition pass. Each candidate stores its mutually-exclusive winning mask,
won area, original area, area ratio, class and score. Counterfactuals only
select a fixed-K subset of these candidates and assemble the stored masks.

The exporter supports `--split train|test|all` and `--file-list`; P1 evidence
uses official train only and the grouped fit/dev/confirm splitter. Artifacts
keep learner features and mask logits in float16 while class logits, winner
maps, native segmentation, official segment metadata, and query provenance are
stored losslessly enough for the corrected assembly sanity checks.

No learner is authorized until dev actionability reaches both the registered
delta and actionable-fraction gates; confirm is a one-time post-freeze check.

## 2026-09-13 exporter correction

The first four-shard train export was stopped after shard 2 exposed a native
sanity mismatch.  The mismatch had two implementation causes: weighted-mask
resizing must follow the frozen processor order, and overlap admission must use
torch float32 semantics (`48/60` is strictly greater than `0.8` in float32).
`models/gssr_p0c_v1/native_admission.py` now matches both details.  A three-image
regression including the failing `000000000109.jpg` passed exact segmentation
and segment metadata checks.  The train export was then resumed with
`--resume`; no learner or test-row selection is authorized.

The resumed full-mask export was subsequently stopped before completion after
storage projection showed it would exceed the remaining filesystem capacity.
The P1 v2 exporter now has a compact profile (`--artifact-profile p1_v2`): it
omits replay-unused mask logits, raw-mask RLE, and inline pixel JSON, while
retaining class logits, decoder/pixel features, fixed winner maps, independent
official segmentation, segment metadata, and query provenance.  A two-image
compact smoke passed exact validation and reduced per-image storage by more than
an order of magnitude.  Four compact train shards are now running in tmux on
GPUs 0–3; old full-mask partial shards remain untouched as failed-run artifacts.
