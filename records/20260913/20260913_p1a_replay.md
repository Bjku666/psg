# P1A counterfactual replay registration

## Scope

`gssr_p1_v1` was registered as P1A actionability work and is now frozen as
`replay_contract_invalidated_before_evidence`: restricting final survivors
changes the pixel-competition population. P0/P0B/P0C remain frozen. No
learner or model-training job is authorized by this registration.
Official test rows are excluded from P1 model selection; the planned split is
grouped by physical `file_name` into fit/dev/confirm.

## Historical implementation (invalidated)

`models/gssr_p1_v1/counterfactual_admission_replay.py` replayed a selected set of
raw decoder query IDs through the frozen native admission routine. The generic
adapter keeps the official postprocessor injectable so that confidence,
pixel-competition, overlap filtering, and panoptic assembly are not silently
reimplemented. `validate_native_replay` is a hard sanity gate; replay output
must match the stored native segmentation and segment records before any
oracle gain is interpreted.

## Smoke attempt

The available `smoke1_r2` artifact was exported with float16 logits. Replaying
those logits produced the same segment count/records but not bit-identical
pixel IDs, so the native sanity gate correctly failed. This is recorded as an
artifact-fidelity blocker, not a positive actionability result. A P1A run must
export float32 logits (or an equivalent lossless native intermediate) and then
rerun the gate before measuring `delta_replay`.

This float-fidelity interpretation is superseded by the corrected
`gssr_p1_v2` contract in `records/20260913/20260913_p1_v2_contract.md`.

## Decision gates

- native replay: exact segmentation and segment records;
- oracle replay: `delta_replay >= 0.06` and actionable fraction `>= 0.4`;
- only after these pass may P1B L0/L1/L2/GSSR learner experiments start.
