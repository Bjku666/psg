# Pre-graph attrition registration

`gssr_p1_v2` is closed as `closed_as_postcompetition_actionability_failure`.
Its corrected dev oracle gained only `+0.0099877106` predicate-balanced
endpoint support, so the post-competition learner ladder is frozen without
execution.

The independent qualification line is `pregraph_attrition_v1`.  It audits
relation endpoints through raw query supply, semantic eligibility, full-pool
pixel competition, and native admission.  The runner requires P0C full
artifacts for raw/semantic stages and writes only endpoint lifecycle,
near-miss, and aggregate metric records; it does not train a model.

The official-train fit partition is the only exploratory population.  Test
artifacts may be used for implementation smoke tests but cannot drive a model
or method decision.  A learned competition-aware repair is not authorized
until competition loss is material and a GT minimum-change oracle demonstrates
material relation-support gain at a small changed-pixel budget.
