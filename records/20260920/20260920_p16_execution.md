# P1.6 metric-exact predicate surgery

## Implementation

Added the independent `models/relation_decision_regret_v2/` package. It keeps
v1 immutable and freezes the legal action space to `KEEP` or `SWAP(predicate)`
for an already selected physical pair. `substitution_teacher.py` evaluates
exact Fair-PSG image-wise counterfactual deltas while copying pair, support,
score, rank and budget. `MERS` is a fit-only CPU utility probe; no confirm/test
data is used and no confirm gate is opened.

## Fit→dev qualification

Command input: the registered 500-image DSFormer hidden compact carriers and
the existing fit/dev subset annotations. Budget 50, predicate depth 3,
100 grouped bootstrap replicates.

| strategy | dev mR | dev R | ΔmR vs native |
|---|---:|---:|---:|
| native KEEP | 53.544 | 48.294 | 0 |
| KEEP/Top-3 exact oracle | 76.958 | 71.134 | +23.414 pp |
| fit-trained Ridge MERS | 49.302 | 48.258 | −4.242 pp |

The exact oracle CI is `[18.859, 27.620]` mR pp (physical-file grouped
bootstrap). It repairs 62.4% of selected actions. This strongly promotes the
scientific phenomenon, but the current simple utility learner fails the method
gate; no claim of a successful learned method is made.

Oracle flip accounting over 20,136 selected pairs gives 659 wrong→correct,
18,064 wrong→wrong and 1,413 correct→correct transitions. No correct→wrong
transition occurred because the per-image oracle explicitly keeps an action
when every legal swap has non-positive exact utility.

The initial fixed-support additivity audit has max residual 1.0 mR fraction.
Thus utility is not assumed additive in the macro metric; the implementation
retains exact image-wise evaluation and treats additivity only as a diagnostic.
