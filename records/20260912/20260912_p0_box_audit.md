# P0 fixed-budget entity admission

The Mask2Former-Swin-Large exporter produced 2,170/2,170 COCO `val2017` test
images in run `psg-test-mask2former-swin-large-finalpanoptic-fulltest-seed0-r4`.
The evaluator joins raw predictions to OpenPSG by `file_name` (OpenPSG scene
`image_id` is a different namespace). The full test population with relations
contains 2,161 images; all have a candidate entry, matching dimensions, and
category IDs in the expected 0--132 range.

Results below are box-IoU diagnostics (strict IoU > 0.5, class-compatible
SingleMPO mapping), not final PSG accuracy:

| budget | score endpoint support | GT-set oracle | delta |
|---:|---:|---:|---:|
| 0.25 | 0.1679 | 0.3371 | +0.1691 |
| 0.50 | 0.3987 | 0.5460 | +0.1474 |
| 0.75 | 0.5705 | 0.6165 | +0.0460 |

Predicate-balanced deltas use 200 paired bootstrap resamples; 95% CIs are
[0.1347, 0.2005], [0.1191, 0.1785], and [0.0286, 0.0644], respectively.
The oracle headroom gate therefore passes for the box diagnostic. Mask-IoU
evaluation remains pending acquisition of COCO panoptic ground-truth masks.

The official Fair PSG `get_match_stats.py` should not be run on a smoke subset
against the full annotation file: it joins by `image_id` and averages over all
rows, which dilutes the result. Filename-aligned, subset-restricted checks give
the expected smoke result (mR@inf_val ≈ 0.536).
